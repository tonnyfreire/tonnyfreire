## 🎯 Principais Entregas e Projetos

- **Segurança & Redes Corporativas:** Planejamento, hardening e implantação de servidores Firewall Linux, definição de políticas de controle de tráfego e gestão de VPNs em ambientes de alta disponibilidade.
- **Automação & Eficiência Operacional:** Desenvolvimento de scripts em Python e aplicações internas voltadas para a automação de rotinas administrativas e controle de ativos de TI.
- **Soluções Web & Segurança Aplicada:** Arquitetura, desenvolvimento e auditoria de segurança de plataformas web, incluindo os projetos **[Decrypt Info](https://www.decryptinfo.com.br)** e **[Factor Arts](https://www.factorarts.com.br)**.
- **Desenvolvimento Assistido por IA:** Exploração e integração de fluxos com Inteligência Artificial para acelerar entregas de software e análise de dados.
